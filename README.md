# Convivo

Plataforma de vivienda compartida: anuncios de habitación, piso o "busco compañero", perfiles y reseñas bidireccionales que solo se abren tras una estancia real.

## Arranque rápido

```bash
npm install
cp .env.example .env.local   # y rellena las variables de Supabase
npm run dev
```

Abre http://localhost:3000. Las convenciones, los comandos y las decisiones de diseño están en [CLAUDE.md](./CLAUDE.md).
